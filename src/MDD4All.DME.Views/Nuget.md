The Blazor components of MDD4All.DME, an editor for object graphs.

One card per object, one line per value, and a shape of its own for a list, an array and
a dictionary. Around that: the start page, the settings dialog, the raw data view, and
every text in German and English.

The components draw what the view models hand them. They know nothing about any
particular data model - which is the point of the whole thing.
